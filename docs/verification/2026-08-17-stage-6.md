## 4. 알려진 한계와 후속 단계로 남긴 것

- 카드의 update·switch 버튼은 비활성 표시이고 로그 뷰·탐색 dialog·환경설정 화면은 단계 7 범위다.
- hover 시각 피드백과 filter 입력 UI는 최소 구성이다. 필터·정렬 intent는 동작하지만 입력창 UI는 단계 7에서 로그 뷰와 함께 다듬는다.
- 키보드 초점 순회는 화면에 보이는 카드 범위다.
- association(더블클릭 실행)은 단계 8이다. 문서는 명령행 인자 또는 파일 dialog로 연다.
- messaging 채널 용량·worker 수는 계획 4.4의 초기값 그대로다. 실사용 계측 후 조정은 단계 7~8에서 판단한다.

## 5. 사용자 수동 검증 checklist

자동 test가 대신할 수 없는 항목이다. `bin\gitman.exe <문서 경로>` 또는 인자 없이 실행해 확인해 주세요.

1. 인자 없이 실행: 빈 상태 안내와 열기 버튼 → 파일 dialog로 `.verison-list` 열기
2. 실제 저장소가 든 문서: 카드 목록, Codicon 상태 아이콘, 브랜치·리비전·작업 트리 요약 표시
3. 카드 refresh 버튼과 전체 refresh(F5): 진행 표시(sync 아이콘) 후 원격 판정 반영
4. 카드 클릭 선택(테두리), 화살표 키 이동, Escape 해제
5. 마우스 휠 스크롤 (카드가 화면보다 많을 때)
6. custom caption: 이동, 최소화·최대화·복원·닫기, Snap Layout, `Alt+Space`
7. 100%/150%/200% DPI에서 배치와 글꼴
8. update·switch 버튼이 흐리게 비활성으로 보이는 것
9. 닫기 시 즉시 종료되고 프로세스가 남지 않는 것
