# 검증 기록 - 단계 8 `S8-D5` 안정화 시험과 실측 검증

## 1. 개요

- 날짜: 2026-08-19
- 대상: `S8-D5` (docs/stage-8-plan.md 5.5, 5.6, 6장)
- 환경: Windows 11 Pro, Git for Windows 2.52.0, 실제 GitHub 접속
- 진행 방식: 체크포인트 종료 시 검수 요청과 제안 커밋 메시지 첨부. 검증은 영향
  범위 테스트만 실행한다 (전체 CTest는 `S8-V1`)

## 2. 자동 안정화 시험 (`stabilization_tests.cpp`, 3개)

- **종료 중 작업 취소 전파**: 실행 중인 update와 진행 중인 탐색이 있는 상태에서
  창 닫기 → 두 작업의 작업별 취소 token과 전역 token이 모두 취소된다. 프로세스
  정리 자체(취소 신호 → 자식 종료 → job object)는 단계 3 계약이 보증한다.
- **종료 후 늦은 event 흡수**: 종료 후 도착한 완료 event가 자동 refresh 연쇄를
  만들지 않고, 새 작업 요청(refresh·탐색)도 제출되지 않는다.
- **대량 로그 부하**: 상한(1,000)의 3배(3,000 record)를 배치로 쏟아도 buffer가
  상한을 지키고, 제거 수가 정확하며, sequence가 단조 증가로 유지되고, 뷰가 제거
  사실(truncated)을 알린다 (plan 3.9).

## 3. GitHub 실측 (`git_network_tests.cpp`, 2개)

네트워크와 외부 서비스에 의존하므로 `GITMAN_NETWORK_TESTS=1`일 때만 실행되고
기본은 skip이다 (CI 결정성). 이 호스트에서 2회 반복 실행해 모두 통과했다.

- **공개 저장소 실측** (`octocat/Hello-World`, 3.6초): https clone 후 provider의
  remote-first refresh가 `up_to_date`·`origin/master`·확인 시각을 보고하고,
  `update --ff-only`가 비대화형으로 실행·성공하며, switch 후보 조회가 실제 원격
  branch group을 돌려준다 (REQ-002, REQ-006, REQ-007).
- **인증 필요 즉시 실패** (1.3초): 자격 증명이 없는 원격에 refresh →
  프롬프트 없이 `authentication_required`로 즉시 실패한다 (plan 3.4, ADR-003).
  test timeout(120초) 안에 1초대로 끝나는 것 자체가 무한 대기 없음의 실측이다.

### 실측 중 확인한 credential helper 동작 (기록)

production은 사용자의 credential helper를 그대로 쓴다 (ADR-003). 이 호스트처럼
GitHub 자격 증명이 저장된 환경에서는 존재하지 않는 저장소 URL에 helper가 응답해
서버가 404("Repository not found" → `error`/저장소 없음)를 돌려준다 — 인증
프롬프트가 없으므로 이 역시 정상 계약이다. "자격 증명 없음" 경로를 실측하기 위해
test는 URL에 다른 username을 박아 helper 조회를 빗나가게 한다 (미스 시
`could not read Password` → `authentication_required`, 실측 1.2초).

## 5. 수동 검증 항목 (S8-V1에서 사용자와 확인)

창·시간·시스템 조작이 필요해 자동화하지 않은 항목이다.

1. **장시간 실행**: 설치본을 2시간 이상 실행하며 주기적 refresh 반복, 작업
   관리자에서 메모리·핸들 수의 단조 증가 없음 확인.
2. **네트워크 단절**: GitHub 원격 카드가 있는 상태에서 어댑터 비활성화 후
   refresh → `offline` 표시와 무한 대기 없음, 재연결 후 정상 복귀.
3. **문서 동시 수정**: 앱이 연 문서를 편집기로 수정·저장한 뒤 앱에서 순서
   변경(저장 유발) → 충돌 notice 표시 확인 (store 계약은 단계 2 test가 보증).
4. **file association 실측**: `bin\gitman.exe --register-file-association` →
   `.version-list` double-click으로 창이 열리고 문서 활성화 →
   `--unregister-file-association` → 잔여물 없음 (`S8-D4` 비고 항목).
5. **대량 로그 UI**: 수만 줄 출력 작업 중 로그 pane 스크롤·복사·지우기 응답성.
