# 검증 기록 - 단계 7 `S7-D4` switch dialog

## 1. 개요

- 날짜: 2026-08-19
- 대상: `S7-D4` (docs/stage-7-plan.md 5장)
- 진행 방식: 사용자 위임에 따른 자동 진행

## 2. 구현 내용

- **카드 switch 버튼을 활성화했다** (REQ-007). 준비된 카드에서
  `begin_switch_intent`로 in-app switch dialog를 열고, 열면서 곧바로
  `query_switch_candidates` 작업을 제출한다. 조회는 카드를 busy로 만들지 않아
  dialog가 열린 동안에도 UI·input thread가 멈추지 않는다.
- **switch dialog 상태 기계**는 logic이 소유한다 (`switch_dialog_state`): 조회
  중 → 후보 목록(remote group 먼저, provider 순서 유지, stale 표시) → 선택 →
  검증 → 실행 → 결과.
  - dialog 수준 검증: 현재 참조인 후보는 확인 버튼을 비활성화하고 사유를
    표시하며 명령을 만들지 않는다. 나머지 검증(존재·저장소 일치·작업 트리)은
    provider가 실행 직전에 재수행한다 (REQ-007의 이중 검증).
  - **tracking branch 생성은 두 단계 확인**이다: `브랜치 만들고 전환` → 안내
    메시지와 `생성 확인` → 실행 시에만 `tracking_branch_confirmed`를 켠다
    (단계 4 계약).
  - 재검증 거부(`executed == false`)는 dialog가 열린 채 거부 사유를 한국어로
    표시하고, 실행된 전환은 성패와 관계없이 dialog를 닫는다 (결과는 카드
    로그·상태로 추적).
  - 늦은 후보 결과는 조회 작업 id로 버리고, 문서 교체 시 dialog를 닫는다.
- **UI**: `switch_dialog_element` — dim 배경(클릭·Esc 취소), panel의 제목(stale
  요약 포함), 종류 아이콘(원격 cloud, 로컬 branch, SVN link)이 붙은 후보 행
  목록(스크롤·clip, 행별 hover·선택 강조), 메시지 줄, 전환 실행·취소 버튼.
  행 정체성은 element id의 owner 값에 index를 담아 구분한다.
- dialog가 열린 동안 휠은 후보 목록을 스크롤한다. Esc 우선순위는 drag 취소 →
  switch dialog → update overlay → 선택 해제다.
- dialog 공용 텍스트 버튼을 `presentation/ui/dialog_elements`로 분리해 update
  overlay와 공유한다.

## 3. 테스트

새 test 7개 (전체 CTest 577 → **584**).

- dialog 열기와 후보 조회 제출, 조회 중 확인 비활성.
- 후보 도착(remote 먼저, stale), 늦은 결과 폐기.
- 현재 참조 후보의 확인 차단과 메시지, 검증 실패 시 명령 0개 (REQ-007).
- tracking branch 두 단계 확인과 `tracking_branch_confirmed` 전달.
- 재검증 거부 시 dialog 유지와 사유 표시, 실행된 전환의 dialog 닫힘, 취소.
- tree의 행·확인·취소·배경 클릭 배선, Esc 취소, 휠의 목록 스크롤 라우팅.
- **실제 Git 저장소 end-to-end**: executor 후보 조회가 `origin/feature`
  (tracking 필요)를 보고하고, 확인된 후보로 switch_to를 실행하면 tracking
  branch가 생성되며 현재 branch가 `feature`로 바뀐다 (Git 없는 호스트는 skip).

## 5. 비고

- SVN 후보는 문서의 `svn_switch_targets` 허용 목록만 온다 (단계 4 계약 그대로).
  이 호스트에 SVN이 없어 SVN 전환의 실측은 단계 8 항목으로 남는다.
- 후보 행 element는 전량 생성하되 배치가 화면 밖 행을 숨긴다. 후보가 수백 개인
  저장소에서 tree 빌드 비용이 문제가 되면 카드 목록처럼 가시 범위 생성으로
  바꾼다 (코드에 주석으로 남김).
