# 검증 기록 - 단계 7 `S7-D2` 선택 카드 전용 하단 로그 뷰

## 1. 개요

- 날짜: 2026-08-19 (구간 시작 2026-08-18)
- 대상: `S7-D2` (docs/stage-7-plan.md 5장)
- 진행 방식: 사용자 위임에 따른 자동 진행

## 2. 구현 내용

- `presentation/view_snapshot.h`: `log_stream_filter`(전체/출력/오류)와 선택 카드
  로그 뷰 모델 `log_view_model`을 추가했다. view snapshot은 선택 카드가 있을 때만
  `log`를 담고, records는 필터 통과분·scroll은 고정 완료 값이라 렌더러는 그대로
  그린다 (REQ-008).
- `presentation/log_presentation`: 필터 판정과 순환, 필터 이름, `HH:MM:SS` 시각
  형식, 클립보드 복사 텍스트 구성을 logic과 UI가 공유하는 순수 함수로 두었다.
- `presentation/list_metrics`: `compute_list_layout`이 로그 pane(논리 160px)을
  반영해 목록 viewport와 pane 영역을 함께 계산한다. 창이 작으면 로그가 먼저
  줄어들어 목록이 음수가 되지 않는다.
- `application/logic_controller`: 로그 뷰 상태(필터, 자동 스크롤, 스크롤 위치)를
  소유한다. 선택 변경 시 기본값으로 초기화하고, 위로 스크롤하면 자동 스크롤이
  꺼지며 맨 아래 도달로 다시 켜진다. intent 3종(`set_log_filter_intent`,
  `set_log_auto_scroll_intent`, `log_scroll_intent`)을 처리한다.
- `presentation/ui/log_view_element`: 하단 pane element다. 헤더에 카드 이름
  (+오래된 로그 제거 표시), 필터 순환·자동 스크롤 토글·복사·지우기 버튼을 담고
  본문은 시각 열과 심각도·스트림별 색으로 record를 그린다. 빈 상태 안내를
  포함하며 pane 배경 클릭은 선택 해제로 흐르지 않는다.
- `presentation/ui/ui_interaction`: 로그 pane 위의 휠은 목록 대신 로그를 스크롤한다.
- `platform/win32/win32_clipboard`: UTF-8 → UTF-16 변환 후 `CF_UNICODETEXT`로
  클립보드에 넣는 adapter다. 새 `ui_command::copy_selected_log`를 UI thread가
  처리해 표시 중(필터 적용 후) 로그를 CRLF로 이어 복사한다.

## 3. 테스트

새 test 9개 (전체 CTest 563 → **572**).

- 필터 규칙과 순환의 공유 함수 검증.
- 복사 텍스트의 시각·스트림 태그와 CRLF 구성.
- 로그 pane이 있는 layout(목록 축소, pane 위치)과 아주 작은 창의 축소 순서.
- 선택 시 view snapshot의 로그 노출과 선택 해제 시 pane 제거.
- 필터가 표시 record를 좁히고 선택 변경이 뷰 상태를 초기화.
- 위로 스크롤 시 자동 스크롤 해제, 맨 아래 도달 시 복귀, 토글 intent.
- tree의 pane 표시와 헤더 버튼 4종의 액션 배선(필터 순환 값, 자동 스크롤 토글
  값, 복사 `ui_command`, 지우기 intent의 카드 id).
- 빈 로그에서 복사·지우기 비활성, 로그 없는 view에는 pane이 없다.
- 로그 pane 위 휠은 `log_scroll_intent`, 목록 위 휠은 `scroll_intent`.

## 5. 비고

- 로그 pane에는 스크롤 막대 시각 표시가 없다. 휠과 자동 스크롤로 동작하며 시각
  막대는 필요 시 후속 작업으로 남긴다.
- 진행 표시(`\r` progress) record는 접지 않고 줄로 표시한다. `progress` 표식은
  유지되어 후속 개선이 가능하다.
- 작업 중 CRLF 일괄 정규화가 checksum 보존 자산(`assets/codicons/*.json`)을
  건드려 빌드가 실패했고, git checkout으로 원복해 해소했다. 자산 디렉터리는
  정규화 대상에서 제외해야 한다는 사실을 기록해 둔다.
