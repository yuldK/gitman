## 7. 사용자 검수 반영 사항

1. 최소 CMake를 4.2.0으로 변경했다.
2. CPU surface를 최소 기준선으로 유지하면서 Direct3D를 기본 renderer로 변경했다.
3. Win32 API를 adapter에 격리하고 로직 경로와 문자열을 `std::u8string`으로 고정했다.
4. 기본 Windows caption 대신 Skia custom caption과 Windows 11 호환 동작을 요구사항으로 추가했다.
5. UWP를 제외하고 Gitman 자체를 단일 `.exe`로 배포하도록 확정했다.
6. CMake install 결과를 `${workspaceRoot}/bin/gitman.exe`로 고정했다.
7. Git 최신 판단과 switch candidate를 remote-first, remote 부재 시 local fallback으로 변경했다.
8. Git update에 optional recursive submodule update를 추가했다.
9. 범용 스레드 메시지 구조는 단계 6 구현 전 별도 사용자 검수를 받도록 차단 gate를 추가했다.
