# 저장소 중심 UI/UX 재검토

2026-11-06. 사용자의 지적에 따라 기능 정의가 저장되는 파일과 사용자가 작업을 시작하는 대상을 구분해 화면을 재검토했다. 이번 변경은 기존 기능 버튼 설계의 문서 전체 진입점·슬롯·단축키 규칙보다 우선한다.

| 화면·동선 | 발견한 문제 | 변경 |
| --- | --- | --- |
| 기능 첫 등록 | 기능이 없으면 카드에 진입점도 없었다. 문서 도구 막대의 우클릭을 알아야 시작할 수 있었다. | 기능이 없는 모든 저장소 카드에 `+`를 표시한다. 카드 메뉴에서 `기능 추가…`와 `기능 관리…`를 항상 제공한다. 문서 메뉴의 기능 편집은 제거한다. |
| 기능 등록 대상 | 새 기능이 모든 저장소에 적용됐다. 편집 창 제목도 저장 파일 이름이었다. | 누른 저장소를 제목·미리보기·기본 적용 대상으로 사용한다. 다른 저장소 전용 기능은 목록에서 제외한다. 공통 기능은 `공통`으로 표시한다. |
| 기능 등록 결과 | 메뉴만 배치가 기본이라 등록해도 결과가 눈에 띄지 않았다. | 새 기능은 선택 저장소의 기능 줄에 표시한다. 등록한 저장소를 선택해 적용 직후 실행 위치가 보이게 한다. |
| 카드 단축키·표시 | 다른 저장소 기능이 카드 슬롯과 단축키 번호를 차지했다. | 저장소에 적용되는 카드 기능 3개를 계산하고 `Alt+1`부터 매긴다. |
| 기능 편집·저장 | 문서 전체 편집기를 저장소 메뉴에 연결하는 것만으로는 다른 저장소까지 수정할 수 있다. | 저장소별 편집 초안을 만들고 적용할 때 다른 저장소의 정의와 원문을 원래 위치에 보존한다. 공통 기능의 기존 적용 대상은 자동으로 바꾸지 않는다. |
| 환경설정 범위 | 문서가 열려 있는지에 따라 저장 대상이 암묵적으로 달라졌다. | `앱 기본값`과 `이 작업공간`을 직접 선택한다. 범위를 바꿔도 양쪽 초안이 유지되며 저장·취소가 두 범위를 처리한다. |
| 설정 상속 | 색과 작은 클릭 가능한 배지에 값의 출처와 되돌리기를 겸하게 했다. | `앱 기본값 사용 중`/`이 작업공간에서 변경함`을 글로 표시한다. 재정의한 항목에만 별도 `기본값 사용` 버튼을 제공한다. |
| 설정 화면 조립 | 탭·색 견본·배지·스크롤 영역을 앱이 직접 그리고 배치했다. | 최신 luil의 탭·선택 묶음·체크·테마 미리보기·색상 선택기·패널·스택·스크롤 영역을 사용한다. |
| 작은 창과 키보드 | 고정된 상단 영역이 항목 공간을 잠식하고, 설정 항목의 초점 이동이 스크롤과 이어지지 않았다. | 낮은 창에서는 설명 영역을 접고 여백을 줄인다. 본문만 스크롤하고 초점 항목이 보이도록 luil의 스크롤 경로를 연결한다. |
| 설정 오류·취소 | 제한 시간 오류가 입력 칸과 떨어져 있었고 배경 클릭으로 초안을 버릴 수 있었다. | 입력 칸에 오류를 표시한다. 배경 클릭은 초안을 버리지 않고 명시적인 취소·Esc에서만 버린다. 다른 범위의 오류도 저장 전에 확인한다. |
| 첫 화면·저장소가 없는 문서 | 등록 안내의 다음 행동이 불분명했다. | 저장소 추가 버튼으로 이동하도록 안내하고 도구 막대 명칭을 `저장소 추가…`로 정리한다. |
| 실행·로그·전환 | 실행 결과와 중지, 선택 저장소 로그, Git 필터·SVN 주소의 대상은 저장소 단위로 연결돼 있었다. | 기존 대상 관계와 안전 확인을 유지한다. 기능 등록 뒤 같은 저장소의 실행 줄로 이어지게 한다. |

환경설정에는 적용 범위, 범위 설명, 카테고리, 항목 카드, 저장·취소를 순서대로 둔다. 경로 선택과 시스템 파일 연결은 기존 동작을 유지하되 설명으로 결과를 알린다. 테마·글꼴 선택은 저장 전 미리보기이며 취소하면 되돌린다.

luil 기준은 원격 `main`을 확인한 `f38b22c65d2e8038ffd1f929454e2604434b5161`이다. 저장소별 카드 표시로 달라질 수 있는 단축키를 신뢰 판정이 놓치지 않도록, 신뢰 해시에 선언된 모든 카드 배치를 포함한다. 예전에 신뢰한 정의 중 영향을 받는 것은 다음 실행에서 한 번 더 확인할 수 있다.

검증 결과와 실제 캡처는 [검증 기록](verification/2026-11-06-ui-ux-redesign.md)에 남겼다. JSON 저장 형식, 알 수 없는 필드 보존, 기존 공통 기능의 적용 범위를 유지한다.
